# Task 23 — Reports and Export

## Objective
Implement report generation for students, teachers, classes, grades, assignments, examinations, attendance, and awards.

## Reports
- Student grade report.
- Student attendance report.
- Student assignment report.
- Student examination report.
- Class grade report.
- Class attendance report.
- Assignment results.
- Examination results.
- Award report.
- Teacher/class workload report.

## Export Formats
- PDF.
- Excel.
- CSV where appropriate.

## Requirements
- Filter by academic year/term.
- Filter by class.
- Filter by subject.
- Filter by student.
- Use dedicated report services.
- Do not place report generation logic directly inside controllers.

## Acceptance Criteria
- Reports produce accurate data.
- Exported files are readable.
- Authorization prevents users from generating unauthorized reports.
