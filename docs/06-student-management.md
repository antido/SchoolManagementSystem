# Task 05 — Student Management

## Objective
Create the student profile and management module.

## Data
Include fields such as:
- user_id
- student_number
- first_name
- middle_name
- last_name
- birth_date
- gender
- address
- contact_number
- status

## Requirements
- Student CRUD.
- Link each student to a User account.
- Search and filtering.
- Student profile page.
- Status management.
- Validation.
- Student number uniqueness.
- Secure authorization.

## Acceptance Criteria
- Admin-authorized users can create students.
- Student account and profile can be managed.
- Student profile displays relevant academic information placeholders.
- Student cannot access another student's restricted administrative functions.
