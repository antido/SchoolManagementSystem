# Task 09 — Subject Management

## Objective
Create subject management and the relationship between classes, subjects, and teachers.

## Data
`subjects`:
- code
- name
- description
- status

`class_subjects`:
- class_id
- subject_id
- teacher_id
- academic_term_id
- status

## Requirements
- Subject CRUD.
- Assign subject to a class.
- Assign teacher to a class subject.
- Academic term association.
- Prevent invalid duplicate assignments.
- Class subject detail page.

## Acceptance Criteria
- A teacher can be assigned to a subject within a class.
- Students can later access activities through class subjects.
