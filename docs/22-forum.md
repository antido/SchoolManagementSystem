# Task 21 — Forum

## Objective
Create a dedicated discussion forum for students and teachers.

## Tables
- forum_categories
- forum_topics
- forum_posts
- forum_post_reactions
- forum_post_reports

## Requirements
- Categories.
- Create topic.
- Reply.
- Edit own post where permitted.
- Reactions.
- Search.
- Pagination.
- Report post.
- Teacher/admin moderation.
- Pin topic.
- Lock topic.
- Delete/moderate inappropriate content.

## Acceptance Criteria
- Authenticated students and teachers can participate according to permissions.
- Moderators can manage reported content.
- Forum permissions are enforced server-side.
