# Task 11 — Teacher Class Assignment

## Objective
Assign teachers to classes and subjects.

## Requirements
- Teacher-class assignment.
- Teacher-subject assignment through `class_subjects`.
- View teacher's classes.
- View class teachers.
- Prevent invalid duplicate assignments.
- Preserve academic-year context.

## Acceptance Criteria
- Teachers see only classes they are assigned to unless authorized otherwise.
- Administrators can manage assignments.
- Historical assignments remain available.
