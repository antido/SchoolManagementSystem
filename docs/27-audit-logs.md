# Task 26 — Audit Trail

## Objective
Track important administrative and academic changes.

## Events
- User created/updated.
- Student created/updated.
- Teacher assigned.
- Student enrolled.
- Assignment created.
- Exam created.
- Grade changed.
- Attendance changed.
- Award granted.
- Forum content moderated.

## Requirements
- Store actor.
- Action.
- Subject/model.
- Previous values where appropriate.
- New values where appropriate.
- Timestamp.
- IP/device information only if justified by privacy policy.

## Acceptance Criteria
- Important changes are traceable.
- Audit data is protected from normal users.
