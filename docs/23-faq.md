# Task 22 — FAQ Module

## Objective
Create a searchable FAQ system.

## Requirements
- FAQ categories.
- FAQ CRUD.
- Publish/unpublish.
- Ordering.
- Search.
- Public/authenticated viewing according to configuration.
- Admin management.

## Acceptance Criteria
- Users can search FAQs.
- Administrators can manage content.
- Only published FAQs appear in the user-facing FAQ page.
