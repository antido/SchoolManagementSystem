# Task 24 — Analytics and Performance Dashboard

## Objective
Add analytics based on existing academic data.

## Metrics
- Enrollment.
- Student performance.
- Grade distribution.
- Attendance trends.
- Assignment completion.
- Examination performance.
- Top-performing students.
- Students needing attention.

## Requirements
- Use efficient aggregate queries.
- Avoid loading thousands of records unnecessarily.
- Add date/academic filters.
- Provide charts and summary cards.
- Respect authorization.

## Acceptance Criteria
- Dashboards display accurate aggregates.
- Queries remain performant with realistic data volumes.
