# Task 27 — Authorization and Security Hardening

## Objective
Secure every module against unauthorized access and common application vulnerabilities.

## Requirements
- Laravel Policies.
- Form Request validation.
- Permission middleware.
- Ownership checks.
- Server-side deadline validation.
- Mass-assignment protection.
- CSRF protection.
- Secure file uploads.
- Rate limiting where appropriate.
- Prevent IDOR vulnerabilities.
- Prevent students from accessing other students' submissions/grades.
- Prevent teachers from modifying unrelated classes.
- Validate all sensitive operations server-side.

## Acceptance Criteria
- Authorization is tested.
- Direct URL manipulation cannot bypass permissions.
- Sensitive records are protected.
