# Task 19 — Student Awards

## Objective
Create an awards system for recognizing student performance.

## Tables
- awards
- student_awards

## Requirements
- Award CRUD.
- Award criteria/description.
- Assign award to student.
- Award history.
- Academic year/class association.
- Optional icon/image.
- Award notification.
- Student award profile section.

## Examples
- Academic Excellence
- Perfect Attendance
- Top Performer
- Most Improved
- Outstanding Student

## Acceptance Criteria
- Authorized users can award students.
- Award history is preserved.
- Students can view received awards.
