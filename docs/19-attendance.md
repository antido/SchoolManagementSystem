# Task 18 — Attendance Management

## Objective
Allow teachers to record and monitor student attendance.

## Table
Create `attendances` with:
- class_id
- student_id
- subject_id where applicable
- teacher_id
- attendance_date
- status
- remarks

## Statuses
- present
- absent
- late
- excused

## Requirements
- Attendance sheet.
- Bulk marking.
- Update attendance.
- Attendance history.
- Student attendance summary.
- Attendance percentage.
- Teacher authorization.

## Acceptance Criteria
- Teachers can record attendance for assigned classes.
- Students can view their attendance.
- Attendance statistics are accurate.
