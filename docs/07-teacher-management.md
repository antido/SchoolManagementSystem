# Task 06 — Teacher Management

## Objective
Create teacher profiles and teacher administration.

## Data
Include:
- user_id
- employee_number
- first_name
- middle_name
- last_name
- birth_date
- gender
- contact_number
- specialization
- status

## Requirements
- Teacher CRUD.
- Link teacher to User.
- Search/filter.
- Profile page.
- Status management.
- Employee number uniqueness.
- HR-specific access where appropriate.

## Acceptance Criteria
- Authorized administrators/HR can manage teachers.
- Teachers have linked user accounts.
- Teacher profile information can be viewed securely.
