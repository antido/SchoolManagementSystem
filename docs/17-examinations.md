# Task 16 — Examination Module

## Objective
Implement timed examinations based on learning activities and questions.

## Requirements
- Exam instructions.
- Start exam.
- Exam availability window.
- Duration.
- Question navigation.
- Save answers.
- Submit exam.
- Attempt limits.
- Automatic submission when time expires.
- Prevent unauthorized access.
- Prevent duplicate attempts according to configuration.

## Optional Enhancements
- Randomize question order.
- Randomize options.
- Auto-save answers.
- Resume interrupted attempts.

## Acceptance Criteria
- Students can safely take an exam.
- Exam timing is enforced server-side.
- Students cannot submit unauthorized or invalid attempts.
