# Task 12 — Role-Based Dashboards and Navigation

## Objective
Create role-specific dashboards and navigation.

## Dashboards
### Super Admin/Admin
- Students
- Teachers
- Classes
- Subjects
- Academic statistics
- Recent activities

### Teacher
- My classes
- Student counts
- Pending submissions
- Upcoming exams
- Attendance summary
- Recent notifications

### Student
- My classes
- Upcoming assignments
- Upcoming exams
- Current grades
- Attendance
- Awards
- Notifications

### HR
- Teacher statistics
- Teacher assignments
- Teacher-related summaries

## Requirements
- Permission-aware navigation.
- Reusable cards.
- Responsive design.
- Empty/loading/error states.

## Acceptance Criteria
- Each role receives an appropriate dashboard.
- Users cannot see navigation items they cannot access.
