# Task 08 — Class Management

## Objective
Implement class/section management.

## Data
- academic_year_id
- name
- code
- grade_level
- section
- description
- status

## Requirements
- Class CRUD.
- Search/filter.
- Assign academic year.
- Class detail page.
- Display assigned teachers and students.
- Prevent duplicate class codes where appropriate.

## Acceptance Criteria
- Authorized users can manage classes.
- Class detail shows academic context.
- Students and teachers can later be assigned to classes.
