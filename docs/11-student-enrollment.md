# Task 10 — Student Enrollment

## Objective
Allow students to be assigned to classes while preserving historical enrollment.

## Table
Create `class_students` with:
- class_id
- student_id
- academic_year_id
- enrolled_at
- status

## Requirements
- Enroll one or multiple students.
- Remove/archive enrollment.
- View class roster.
- View student's enrollment history.
- Prevent duplicate active enrollment in the same class/academic context.
- Preserve historical records.

## Acceptance Criteria
- Students can be enrolled in classes.
- Class rosters are accurate.
- Enrollment history is preserved.
