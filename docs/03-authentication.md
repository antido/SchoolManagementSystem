# Task 02 — Authentication

## Objective
Implement secure authentication using Laravel Breeze with Inertia React and TypeScript.

## Requirements
- Login.
- Logout.
- Password reset.
- Forgot password.
- Registration if enabled by project requirements.
- Email verification if enabled.
- Profile page.
- Password change.
- Account status handling.
- Protect authenticated routes.
- Provide a clean authentication UI.

## Acceptance Criteria
- Unauthenticated users cannot access protected pages.
- Authenticated users can log out.
- Invalid credentials are handled correctly.
- Validation errors display in React.
- User profile can be updated.
- Password changes are validated securely.
