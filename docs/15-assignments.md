# Task 14 — Assignment Module

## Objective
Implement teacher-created assignments and student submissions.

## Requirements
- Create/edit/delete assignment.
- Instructions.
- Attachments.
- Start/due dates.
- Total points.
- Draft/published status.
- Student assignment list.
- Assignment detail.
- Submission form.
- File upload.
- Late submission detection.
- Teacher grading.
- Feedback.

## Tables
Use learning activities and create submission support such as `activity_submissions`.

## Acceptance Criteria
- Teacher can publish an assignment.
- Enrolled students can see it.
- Students can submit before/after the deadline according to rules.
- Teacher can grade and provide feedback.
- Submission status is visible.
