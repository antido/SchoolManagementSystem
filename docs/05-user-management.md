# Task 04 — User Management

## Objective
Create administration functionality for managing authenticated users.

## Requirements
- User list.
- Search.
- Filtering.
- Pagination.
- Create user.
- Edit user.
- Activate/deactivate user.
- Reset password where appropriate.
- Assign roles.
- View user details.
- Confirmation dialogs for destructive actions.

## Acceptance Criteria
- Admins can manage users according to permissions.
- Role assignment works.
- Disabled users cannot authenticate.
- Validation is performed using Form Requests.
- Controllers remain thin and business logic is placed in Services/Actions.
